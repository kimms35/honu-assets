# honu_dev 제작 틀

honu_dev 채널의 카드뉴스와 릴스를 같은 디자인으로 다시 만들기 위한 틀입니다.

## 공통 스타일

- 캐릭터: 연한 파랑 픽셀 슬라임 (16×14 격자, 검정 세로 눈 두 개)
- 말투: 친근한 존댓말, 과장 금지, 숫자는 사실만
- 부탁은 한 게시물에 하나만 (저장 또는 공유)
- 해시태그는 5개 이하

## 카드뉴스 (`cardnews/`)

- 크기 1080×1350, 9장 구성
- 색: 본문 바탕 `#F7F6F3`, 글자 `#1F1F1F`, 보조 글자 `#5F5E5B`, 형광펜 `#FFE27A`, 표지·마무리 바탕 `#1F1F1F`
- 구성: 표지(상황형 질문) → 왜 봐야 하는지 → 본문 5장 → 한눈에 보기 → 마무리(저장 유도)
- 본문 장은 제목·박스·설명 위치를 모든 장에서 똑같이 유지
- `project/*.dc.html` 의 글자만 바꾼 뒤 `cardnews/` 폴더에서 `mkdir -p shots && node render.js` 를 실행하면 `shots/` 에 PNG가 생김
- 만든 PNG는 `cardnews/<날짜>-<주제>/01.png …` 로 올리고, 그 주소로 예약 발행

## 릴스 (`reel/`)

- 크기 1080×1920, 30fps, 20초 안팎, 음악 없음 (음악은 올릴 때 직접 추가)
- 색: 하늘색 바탕, 노랑 블록, 빨강 강조
- 첫 프레임부터 훅 문구가 보여야 함
- 글자는 y 230~1440 안에, 아래쪽 오른편(x 850 이후)은 비워 둠
- `python3 make_reel.py stills` 로 장면 미리보기, `python3 make_reel.py` 로 장면별 mp4 생성 후 ffmpeg concat 으로 합침
- 장면 문구는 `make_reel.py` 의 `scene_*` 함수에서 수정
