> **검증 범위:** 업로드 보고서의 출처 표시(`citeturn…`)는 다른 AI 도구의 내부 인용 표시라서 원문 링크를 따라갈 수 없다. 핵심 주장은 웹 검색으로 하나씩 다시 대조했다. 다만 이 세션은 네트워크 제한 때문에 관세청, 산림청, DART 같은 원문 페이지를 직접 열 수 없어 **기사와 검색 요약 수준의 확인**이다. "미확인"은 틀렸다는 뜻이 아니라, 이번 검색으로 근거를 찾지 못했다는 뜻이다.

## 1. 한눈에 보는 결론

1. **업로드 보고서의 큰 방향은 맞다.** 판단은 "조건부 GO, 코드보다 수동 매칭 먼저"다. 수요 기반이 되는 핵심 통계(수출기업 101,792개사 등)도 확인됐다. 법무 논리(PG 등록, 도급 책임, 개인정보)도 기존 보고서의 조사와 같다.
2. **경쟁사 분석에 중요한 오류와 누락이 있다.**
   - 가장 직접적인 경쟁사로 든 **"SendPackage"는 존재를 확인하지 못했다.**
   - 반대로 **리우의 「포장포스」**는 빠져 있다. 포장포스는 국내 최초 포장재 중개 플랫폼을 표방하고, 사진을 올리면 24시간 안에 견적을 주며, 2020년 기준 입점 업체 100여 곳에 중개 프로젝트 약 5,000건을 기록했다.
   - 업로드 보고서가 SendPackage에 붙인 특징(사진 한 장 견적, 입점 업체 비교)은 포장포스와 거의 같다. 이름을 잘못 적었거나 다른 서비스와 섞였을 가능성이 높다.
3. **이 오류 때문에 결론이 바뀌지는 않는다. 오히려 업로드 보고서의 포지셔닝이 더 설득력을 얻는다.**
   - 일반 포장재 견적 중개는 이미 여러 곳이 하고 있다: 포장포스, 패커티브, 로지스인.
   - 그러니 **"중량·고가 설비의 수출포장 + 현장작업 + ISPM 15"** 처럼 좁고 전문적인 곳으로 들어가야 한다는 업로드 보고서의 주장이 맞다.
   - 기존 보고서가 1순위로 꼽은 "산업포장(골판지 포함)"은 범위가 넓었다. **중량물·수출 목재포장으로 좁히는 것이 옳다.**
4. **수익모델은 두 보고서를 합친 단계형으로 간다.**
   - 초기: 고객과 포장업체가 직접 계약하고, 플랫폼은 성공수수료나 리드비를 받는다. 법적 위험이 가장 낮다.
   - 이후: 보험과 계약 양식이 갖춰지면 플랫폼 명의로 발주하는 관리형 모델로 넘어간다.

## 3. 논리 검토: 받아들일 것, 고칠 것

### 받아들일 것

- **포지셔닝:** 단순한 업체 목록이 아니라 "수출·중량설비 포장 RFQ 조달대행 + 검증된 공급망"으로 간다. 일반 포장재 중개는 포장포스와 패커티브가 이미 하고 있어 이 판단이 더 강해진다.
- **수요 측 핵심 문제:** 업체를 찾는 것보다 "누가 이 작업을 실제로 할 수 있는지" 판단하기 어렵다는 점이 진짜 문제다. 그래서 역량 데이터(최대 중량, 현장작업, 방청·진공, ISPM)가 해자가 된다.
- **납기의 가치:** 고객에게 필요한 것은 견적 수십 개가 아니라 "24시간 안에 가능한 업체 2~3곳"이다.
- **검증 방식:** 랜딩페이지와 수동 매칭으로 먼저 검증하고, 과거 행동을 묻는 인터뷰를 하며, GO·PIVOT·NO-GO 기준을 정량으로 둔다.
- **초기 제외 기능:** AI 자동견적, 3D 설계, 자체 에스크로.

## 4. 최종 포지셔닝

> **"기계·설비 수출기업을 위한 24시간 산업포장 비교견적. ISPM 15 대응과 현장작업이 가능한 검증 업체 2~3곳을 하루 안에 연결해 드립니다."**

- **타깃 고객:**
  - 인천, 김포, 시흥·안산, 화성, 평택, 천안·아산에 있는 기계·장비·전기전자 수출기업(해외영업, 물류, 구매 담당)
  - 포워더(국제물류주선사)
  - 공장 이전·설치 업체

- **제외(초기):** 소량 리테일 박스(패커티브), 일반 포장재 구매(포장포스, 로지스인), 3PL

### 5.2 P1 발견·수동 매칭 (2~5주차)

**인터뷰 목표**

| 대상 | 인원 | 찾는 경로 |
|---|---|---|
| 발주자(해외영업, 물류, 구매, 생산관리, 설비업체 대표) | 25명 | 링크드인, 산단 협회, 지인 소개, 수출 관련 커뮤니티, 포워더 소개 |
| 포워더·설치업체 | 5명 | 포워더는 포장을 대신 발주하는 경우가 많아 소개 채널이 될 수 있다 |
| 산업포장·수출포장 업체 | 15~20곳 | 공급자 목록에 전화한 뒤 방문. 방문할 때 작업장 사진과 역량을 기록 |

**주차별 할 일**

| 주차 | 발주자 | 공급자 | 매칭 |
|---|---|---|---|
| 2주차 | 인터뷰 8명 | 전화 50곳, 응답 업체 정리 | 첫 RFQ 1~2건 |
| 3주차 | 인터뷰 8명 | 방문 6곳, 프로필 작성 | RFQ 3건 |
| 4주차 | 인터뷰 9명 + 포워더 3명 | 방문 6곳 | RFQ 3건 |
| 5주차 | 포워더·설치업체 2명, 중간 정리 | 방문 3~8곳, 응답 빠른 상위 15곳 확정 | RFQ 2~3건, 누적 10건 |

**수동 매칭 절차(한 건당)**
1. RFQ를 받으면 30분 안에 접수 확인을 보낸다.
2. 빠진 정보(사진, 무게중심, 크레인 등)를 전화로 보완한다.
3. 역량이 맞는 업체 3곳에 RFQ를 보낸다. 항상 3곳으로 제한해 공급자가 과당경쟁이라고 느끼지 않게 한다.
4. 견적 PDF를 모아 비교표(가격, 납기, 포함 범위, ISPM, 현장작업, 조건)를 만든다.
5. 24시간 안에 고객에게 비교표를 보낸다.
6. 채택 여부와 이유를 기록한다.
7. 작업 완료 사진과 평가를 받는다.
- **매 건 기록할 것:** 매칭에 쓴 시간(분), 견적 수, 첫 견적까지 걸린 시간, 금액, 채택 여부, 탈락 이유.

**인터뷰 필수 질문(과거 행동 기준)**
- 발주자:
  - 최근 세 번의 산업포장 발주에서 무엇을 포장했나. 업체는 어떻게 찾았고, 견적은 몇 곳에서 받았나.
  - 처음 문의부터 확정까지 얼마나 걸렸나. 건당 금액은 어느 범위였나.
  - 기존 거래처를 못 쓴 경우는 언제였나(긴급, 타지역, 특수 규격).
  - 품질·검역 사고를 겪은 적이 있나.
  - **포장포스, 숨고, 검색 등 다른 경로를 써 봤나. 왜 해결이 안 됐나.** ← 추가
  - 연간 외주 포장은 몇 건, 총 얼마 정도인가. ← TAM 변수
- 공급자:
  - 월 문의 건수와 실제 수주 건수, 견적 하나 쓰는 데 걸리는 시간.
  - 거절하는 프로젝트와 그 이유, 이동할 수 있는 거리.
  - 새 고객은 어떻게 얻나. 소개수수료를 낸다면 어떤 조건이어야 하나.
  - 견적 뒤 직거래를 선호하는 이유는 무엇인가.
  - **ISPM 15 열처리를 직접 하나 아니면 외주인가. 등록증이 있나.** ← 추가

**P1 종료 기준:** 발주자 중 "연 2회 이상 외주"가 40% 이상이고, RFQ 중 견적 2개 이상 확보가 70% 이상이며, 첫 견적까지 24시간 이내.

### 5.3 P2 유료 검증 (6~9주차)

| 할 일 | 세부 내용 |
|---|---|
| 공급자 과금 실험 | A안: 성공수수료로 수주 금액의 5~8%. B안: 유효 리드 고정비로 건당 3만~10만원. 업체마다 하나를 제안하고 수락률을 기록 |
| 발주자 과금 실험 | "긴급 소싱 fee"로 건당 5만~20만원. 72시간 안에 납기가 필요한 건에만 제안 |
| 계약 구조 | 고객과 포장업체가 직접 계약한다. 플랫폼은 공급자와 **중개 수수료 약정서**를 맺는다(수수료율, 산정 기준, 지급 기한, 직거래 시 처리, 기간) |
| 표준 발주서 | 7.3절 항목. 고객과 업체 모두에게 무료로 주는 "일이 줄어드는 도구" |
| 세금계산서 | 플랫폼은 수수료분만 공급자에게 발행 |
| 목표 | 실제 발주 5건 이상, 수수료를 실제로 낸 공급자 1곳 이상, 평균 거래액 150만원 이상 |

**단위경제 민감도**(업로드 보고서 가정: 공헌이익 = 건당 수수료 − 변동비 5만원, 월 고정비 650만원은 대표 인건비 400만원 포함)

| 평균 거래액 | 수수료율 | 건당 수수료 | 공헌이익 | 손익분기(월 650만원) |
|---|---|---|---|---|
| 150만원 | 8% | 12만원 | 7만원 | 93건 |
| 250만원 | 8% | 20만원 | 15만원 | 44건 |
| 250만원 | 12%(관리형 마진) | 30만원 | 25만원 | 26건 |
| 400만원 | 8% | 32만원 | 27만원 | 25건 |
| 400만원 | 12% | 48만원 | 43만원 | 16건 |

→ **거래액이 150만원 근처에 머물면 수수료만으로는 사업이 되기 어렵다.** 고액 건(중량 설비, 200만원 이상)의 비중을 높이거나, P5의 관리형 마진과 운송·적입 묶음이 꼭 필요하다. P2에서 실제 평균 거래액을 확인하는 것이 가장 중요한 실험이다.

### 5.4 P3 판정 (10~13주차)

- 데이터를 정리한다: RFQ 수, 견적 확보율, 첫 견적 시간, 전환율, 평균 거래액, 공급자 유료 지불 비율, 재주문·소개, 건당 매칭 시간.
- 6장 기준표에 넣어 판정한다.
- **GO:** P4로 간다.
- **PIVOT:** 6.2절의 대안 가운데 데이터가 가리키는 쪽을 고른다.
- **NO-GO:** 개발에 돈을 더 쓰지 않는다. 모은 공급자 데이터와 인터뷰 결과를 정리해 둔다.

### 5.5 P4 MVP (4~6개월차)

**기능 범위**

| 포함 | 제외 |
|---|---|
| 기업·담당자 가입(사업자번호를 국세청 API로 자동 검증) | AI 자동가격, 3D 포장설계 |
| RFQ 작성(사진·도면 업로드, 치수, 중량, 지역, 희망일, 도착국, ISPM 여부) | 실시간 채팅 |
| 공급자 역량 프로필 + "검증됨" 배지(사업자, 공장등록, 열처리 등록증, 보험, 방문 실사) | 자체 결제·에스크로 |

### 5.6 P5 확장 (7~12개월차)

1. **관리형 모델 도입:**
   - 고액·긴급 건부터 플랫폼 명의로 발주하고 마진 10~18%를 받는다.
   - 그 전에 갖출 것: 영업배상책임보험, 표준 하도급 계약서, PG 에스크로 연동(직접 보관하지 않는 구조), 변호사 검토.
2. **세그먼트 확장:**
   - 순서: 반도체·자동화장비 → 공작기계·산업기계 → 전시·해외설치 장비 → 해외공장 이전 설비.
   - 업종별 RFQ 양식을 각각 만든다.
3. **번들:** 포장에 국내 운송과 컨테이너 적입을 묶어 건당 거래액을 높인다.
4. **공급자 Pro:** 월 9.9만~29.9만원으로 A/B 테스트한다. 견적 관리 도구, 노출 우선순위, 실적 리포트를 준다.
5. **정부 연계:** 수출바우처의 물류·포장 분야 수행기관(공급기업) 등록을 검토하고, 혁신바우처와도 연계한다.
6. **권역 확장:** 첫 권역의 지표가 유지될 때만 동남권(창원·김해·부산 명지녹산)으로 넓힌다.

## 6. 판정 기준

### 6.1 GO / PIVOT / NO-GO 기준표

업로드 보고서 기준에 두 항목을 더했다(✚).

| 지표 | GO | PIVOT | NO-GO |
|---|---:|---:|---:|
| 발주자 중 "연 2회 이상 외주" | ≥40% | 20~40% | <20% |
| RFQ 중 견적 2개 이상 확보 | ≥70% | 40~70% | <40% |
| 첫 견적까지 걸린 시간 | ≤24시간 | 24~48시간 | >48시간 |
| 실제 발주 전환율 | ≥20% | 8~20% | <8% |
| 평균 거래액 | ≥150만원(가능하면 250만원 이상) | 50만~150만원 | <50만원 |
| 공급자 수수료 지불 의향 또는 실제 지불 | ≥30% | 10~30% | <10% |
| 90일 내 반복 발주·소개 | ≥20% | 5~20% | <5% |
| ✚ "기존 대체재(포장포스, 숨고, 지인)로 해결 안 됨"이라고 답한 발주자 | ≥50% | 25~50% | <25% |
| ✚ 건당 매칭 소요 시간 | ≤1.5시간 | 1.5~4시간 | >4시간 |

### 6.2 PIVOT 대안

| 신호 | 대안 |
|---|---|
| 수요는 있는데 공급자가 수수료를 거부 | 발주자 유료 모델("긴급 소싱 대행" 정액) |
| 공급자는 견적 작성이 부담이라 하는데 신규 수요는 적음 | **포장업체용 견적·CRM SaaS**(견적서 자동 작성, 고객·이력 관리) |
| 일반 포장재 문의가 더 많음 | 포장포스나 로지스인과 제휴, 또는 일반 제조조달 플랫폼의 산업포장 부문으로 |
| 포워더 소개 비중이 높음 | 포워더용 B2B2B 파트너 프로그램(포워더가 RFQ를 대신 올림) |

## 7. 운영 양식

### 7.1 표준 RFQ(고객 입력)

필수 입력은 7개다.
1. 포장 대상(품명·용도) + 사진 1장 이상
2. 치수(가로×세로×높이)와 중량
3. 포장 장소(주소) / 업체 공장 반입 여부
4. 희망 완료일
5. 도착국(수출이면 ISPM 15 자동 체크)
6. 포장 방식 희망(목상자, 스키드, 진공, 방청, 모름)
7. 연락처(정보 제공 동의 포함)

선택 입력: 무게중심, 크레인·지게차 유무와 담당, 실내·실외 작업, 방청 기간, 도면, 예산 범위, 컨테이너 적입·운송 필요 여부.

### 7.2 공급자 프로필(검증 항목)

| 구분 | 항목 | 검증 방법 |
|---|---|---|
| 자동 | 사업자 상태(계속, 휴업, 폐업) | 국세청 상태조회 API(무료) |
| 자동 | 공장등록 여부, 업종 | 공공데이터포털 전국등록공장현황 |
| 자동 | 고용 규모 | 국민연금 가입 사업장 데이터 |
| 서류 | ISPM 15 열처리 등록증, 생산자 코드, 유효기간 | 업체가 올린 사본 + 검역본부 확인 |
| 서류 | 보험(영업배상, 화물) | 증권 사본 |
| 실사 | 작업장 면적, 최대 중량, 장비, 현장작업 가능 지역 | 방문, 사진 |
| 운영 | 응답 속도, 견적 채택률, 완료 평가 | 플랫폼 데이터 |
| 선택 | 기업 신용 | KODATA KOapinet. 고액 건에만, 비용은 견적 받아 확인 |

### 7.3 표준 발주서 항목

포장 대상과 수량, 치수·중량, 포장 사양(목재 규격, 방청·방습·진공), ISPM 마크, 작업 장소(실내·실외), 장비와 책임자(크레인·지게차), 작업일, 완료 기준, 작업 후 사진 제출, 추가작업 요율, 파손 책임 범위, 재작업 조건, 대금 지급 조건.

## 8. 법무·규제 점검표

| 항목 | 시점 | 할 일 |
|---|---|---|
| 사업자등록(업종: 사업지원 서비스 또는 중개) | P0 | 통신판매업 신고가 필요한지 세무사·변호사에게 확인. 순수 B2B면 해당하지 않을 수 있음 |
| 이용약관: 중개자 고지, 책임 범위 | P1 | "거래 당사자가 아님"을 고지하고 분쟁 처리 절차를 적는다 |
| 개인정보 처리방침, 제3자 제공 동의 | P0 | 받는 곳, 목적, 항목, 보유기간을 명시하고 최대 3곳에만 제공 |
| 공급자 중개 수수료 약정서 | P2 | 직거래가 드러났을 때 처리 조항은 과하지 않게 둔다(관계 악화 위험) |
| 관리형 도급 전환 | P5 | 계약 당사자가 되면 민법 제667조 하자담보 책임이 생긴다. 보험과 하도급 계약서를 갖추고 하도급법이 적용되는지 확인 |
| 결제 | P5 | 직접 보관하지 않는다. 등록된 PG의 에스크로나 지급대행을 쓴다 |
| 리뷰 | P4 | 완료된 거래만 평가할 수 있게 하고, 직원이 쓴 리뷰는 금지(표시광고법) |
